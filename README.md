# CS SOFT SERVER

Браузерный CS-подобный deathmatch-сервер, в котором **каждому игроку каждый раунд выдаётся случайный софт**: аимбот, вх, быстрая стрельба, без отдачи, банихоп, спидхак, триггербот, радар, бесконечные патроны, двойной урон и мемный спинбот. Софты реально работают на сервере — это не картинка, а игровая механика.

Побеждает тот, кому повезло с дропом и кто успел этим воспользоваться.

## Как зайти

### Вариант 1 — локально (проще всего, 2 минуты)

```bash
git clone <этот-репозиторий>
cd cs-soft-server
npm install
npm start
```

Открыть в браузере: **http://localhost:3000**
Вписать ник → «В ИГРУ». Всё, ты на сервере. Чтобы играть с другом — он открывает тот же адрес; если играет с другого компьютера в той же сети, отдай ему `http://<твой-IP>:3000` (порт 3000 пробросить в файрволе).

### Вариант 2 — публичный сервер (чтобы зайти по ссылке с любого устройства)

Любой хостинг, который умеет Node.js:

```bash
# на сервере/в контейнере
PORT=3000 npm start
```

Сервер слушает `0.0.0.0`, поэтому подойдёт Render / Railway / Fly.io / VPS + nginx-прокси. Открываешь выданный домен или IP:порт — и играешь.

> Проверка, что сервер поднялся: `curl http://localhost:3000/health` → `{"ok":true,...}`

## Управление

| Действие | Клавиша |
|---|---|
| Движение | `W` `A` `S` `D` (или стрелки) |
| Прицел | мышь |
| Стрельба | ЛКМ (зажми — автомат) |
| Перезарядка | `R` |
| Пауза/меню | `Esc` |

На телефоне: стик слева — движение, свайп по экрану — прицел, кнопки «ОГОНЬ» и «R» справа.

## Правила сервера

- Раунд длится **60 секунд**, потом **8 секунд** перерыва с таблицей итогов и следующим дропом.
- В начале каждого раунда **все живы, HP 100, магазин полный**, все софты перебрасываются заново — прошлый раунд ничего не значит.
- Убил → +1 в счёт раунда. Умер → респавн через 2.5 секунды в дальней точке карты.
- Шанс **двойного дропа — 15%**: тогда у тебя два софта одновременно.
- Аимбот и триггербот не стреляют через стены: работает только видимая цель.

## Структура проекта

```
server/index.js     HTTP + socket.io, раздача статики, /api/softs, /health
server/game.js      игровой цикл 30 Гц: движение, стрельба, раунды, урон, респавн
server/softs.js     пул софтов, редкости, веса и ролл дропа
server/map.js       карта арены (симметричная, 40x24 тайла) и точки респавна
public/index.html   меню и HUD
public/client.js    рендер на canvas, ввод, HUD, радар, эффекты
public/style.css    оформление
scripts/            автотесты (npm test)
```

Сервер авторитетный: клиент отправляет только ввод (направление, кнопки), все попадания, урон и дроп считаются на сервере — читерить через консоль браузера не выйдет.

## Настройки

Переменные окружения:

```bash
PORT=3000            # порт
ROUND_TIME=60        # длительность раунда, сек
INTERMISSION=8       # длительность перерыва, сек
```

## Тесты

```bash
npm test
```

- `combat-test.js` — проверяет, что каждый софт реально меняет механику, что аимбот убивает, пули останавливаются стенами и софты меняются каждый раунд.
- `smoke-test.js` — поднимает сервер, подключает двух ботов, проверяет HTTP, выдачу софтов, раунды и снапшоты.
- `client-test.js` — прогоняет клиент в jsdom и ловит ошибки рендера/HUD.
